# OAI221

Inverted output AND-OR gate with two two-input OR gates and one direct input to AND gate

## Pin information

| Pin   | Description   |
| :-:    | :-            |
| A | Input A, connected to first OR gate |
| B | Input B, connected to first OR gate |
| C | Input C, connected to second OR gate |
| D | Input D, connected to second OR gate |
| E | Input E, connected to AND gate |
| Y | Output |
| VDD | Power supply |
| VSS | Ground |


## Logic function and Truth table

### Logic function (Python)
<div align="center">
Y = ~((A | B) & (C | D) & E)
</div>

### Logic function (Boolean)
\\[ Y = \overline{(A + B) \cdot (C + D) \cdot E} \\]

### Truth Table for Y

| 1 | - | 1 | - | 1 | 0 |
